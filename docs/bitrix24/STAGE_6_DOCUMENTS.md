# Этап 6. Документы в Битрикс24

## Что работает

- Новый файл кабинета ставится в надёжную очередь синхронизации.
- В карточке сделки клиента создаётся комментарий таймлайна с прикреплённым файлом Диска Битрикс24.
- Повторная обработка не создаёт дубль: используются уникальный ключ операции и служебная метка в таймлайне.
- Одинаковое содержимое нельзя загрузить дважды для одного клиента: дубль определяется по SHA-256.
- В очереди и журналах нет содержимого файла, base64, исходного имени файла или данных клиента.
- Если сделка клиента ещё не создана, файл ждёт её синхронизации.

## Защита загрузки

Кабинет ограничивает размер до 10 МБ, проверяет расширение, MIME-тип и базовую сигнатуру PDF, JPEG, PNG, DOC и DOCX. Эта проверка отсекает очевидно подменённые файлы, но не является антивирусной проверкой.

## Важное ограничение

Удаление файла из кабинета после успешной синхронизации не удаляет копию из таймлайна Битрикс24. Это сделано для сохранности истории CRM. Операция удаления блокируется, пока синхронизация не завершена.
