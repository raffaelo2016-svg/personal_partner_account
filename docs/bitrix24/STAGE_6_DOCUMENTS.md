# Этап 6. Документы в Битрикс24

## Что работает

- Новый файл кабинета ставится в надёжную очередь синхронизации.
- Для каждого партнёра новый документ загружается в Диск Битрикс24 по структуре: «ПАРТНЕРЫ» → папка партнёра → папка клиента по ФИО → «Первоначальные документы».
- Проверка и создание недостающих папок выполняются только при фактической загрузке документа из кабинета.
- Существующие папки переиспользуются; создаётся только отсутствующая часть структуры.
- Имя файла остаётся узнаваемым; к нему добавляется короткий служебный идентификатор для защиты от дублей при повторной синхронизации.
- Имя папки партнёра берётся из названия партнёра или компании в кабинете.
- Если названия двух партнёров совпадают, к папке более позднего партнёра добавляется короткий служебный идентификатор, чтобы документы не смешивались.
- В карточке сделки клиента создаётся комментарий таймлайна со ссылкой на файл в папке «Первоначальные документы».
- Повторная обработка не создаёт дубль: используются уникальный ключ операции и служебная метка в таймлайне.
- Одинаковое содержимое нельзя загрузить дважды для одного клиента: дубль определяется по SHA-256.
- В очереди и журналах нет содержимого файла, base64, исходного имени файла или данных клиента.
- Если сделка клиента ещё не создана, файл ждёт её синхронизации.
- Кабинет ищет корневую папку «ПАРТНЕРЫ» на общем диске и находит или создаёт внутри неё папку партнёра.
- Файл, который сотрудник прикрепил к новому комментарию в таймлайне известной сделки, импортируется обратно в карточку клиента и сохраняется в MinIO.
- Файл, который сотрудник поместил напрямую в папку клиента «Первоначальные документы» на Диске Битрикс24, импортируется в кабинет при открытии списка документов.
- В административной карточке должника есть кнопка «Загрузить для партнёра»: такие файлы сразу видны партнёру и затем синхронизируются в ту же папку Битрикс24.
- Исходное имя входящего файла сохраняется; тип документа в кабинете устанавливается как «Другое», пока сотрудник не классифицирует его вручную.
- Повторное событие Битрикс24 не создаёт вторую копию: проверяются внешний ID и SHA-256 содержимого.

## Как сотруднику передать документ из Битрикс24 в кабинет

1. Открыть сделку клиента в воронке «Арбитраж».
2. Добавить новый комментарий в таймлайн и прикрепить к нему файл.
3. Сохранить комментарий. Поддерживаются PDF, JPG/JPEG, PNG, DOC и DOCX размером до 10 МБ.
4. Файл появится в документах связанного клиента в кабинете. При временной ошибке система повторит импорт автоматически.
5. Если импорт окончательно не выполнен, администратор увидит запись «Входящий документ» в разделе «Требует внимания», исправит причину и нажмёт «Повторить».

## Защита загрузки

Кабинет ограничивает размер до 10 МБ, проверяет расширение, MIME-тип и базовую сигнатуру PDF, JPEG, PNG, DOC и DOCX. Скачивание разрешено только с подключённого домена Битрикс24. Эта проверка отсекает очевидно подменённые файлы, но не является антивирусной проверкой.

## Важное ограничение

Удаление файла из кабинета после успешной синхронизации не удаляет файл из Диска Битрикс24 и ссылку из таймлайна. Это сделано для сохранности истории CRM. Операция удаления блокируется, пока синхронизация не завершена.
