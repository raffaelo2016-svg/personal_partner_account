1. Открой новую сессию Cursor Agent (Opus 4.6)
2. Скопируй весь блок между `--- НАЧАЛО ПРОМТА ---` и `--- КОНЕЦ ПРОМТА ---`
3. После промта напиши какие задачи выполнить, например:
   - **Сессия 1:** `Выполни задачи 0.0, 0.1, 0.2`

═══════════════════════════════════════════
 3. ЖЁСТКИЕ СОГЛАШЕНИЯ
═══════════════════════════════════════════

Python / Backend:
• Всё через poetry run. Никогда pip install.
• Модели: Mapped[str] для статусов. Enum-ы — только в Pydantic-схемах.
• server_default=func.now() для timestamp-полей (не default=func.now()).
• Суммы денег — int в копейках. 15 000 ₽ = 1_500_000.
• Логирование — structlog. Никогда print().
• Ошибки — { "detail": "...", "code": "ERROR_CODE" } + правильный HTTP-код.
• RBAC — каждый эндпоинт проверяет роль. Партнёр видит ТОЛЬКО свои данные.
• Seed — идемпотентный. Повторный запуск не падает (проверять по email/ключу).
• Бизнес-логика — в services/, не в api/. Роуты только вызывают сервис.

TypeScript / Frontend:
• Серверные данные — ТОЛЬКО через React Query. Zustand — только для auth и UI.
• Формы — react-hook-form + zod. Не useState + handleChange.
• Даты — ISO 8601 из API, форматирование date-fns на фронте.
• Деньги — отображение через утилиту formatMoney(kopecks).
• НЕ трогать components/ui/ — это shadcn, они работают.

═══════════════════════════════════════════
 7. ТИПИЧНЫЕ ОШИБКИ — НЕ ДОПУСКАЙ ИХ
═══════════════════════════════════════════

1. CIRCULAR IMPORT: Celery использует autodiscover_tasks — не импортируй таски в celery_app.py напрямую.
2. ALEMBIC + ASYNCPG: Для миграций нужен sync-драйвер. В env.py использовать sync URL (psycopg2), а не asyncpg.
3. CORS_ORIGINS: В .env это строка. В config.py парсить через json.loads или validator → list[str].
4. SEED ДУБЛИКАТЫ: Перед созданием записи всегда проверять существование (SELECT WHERE email=...).
5. PYDANTIC V2 СИНТАКСИС: model_validator вместо root_validator, model_config вместо class Config.
6. SQLALCHEMY 2.0 СИНТАКСИС: Mapped[], mapped_column(), select() вместо legacy Query.
7. REACT QUERY V5 СИНТАКСИС: useQuery({ queryKey: [...], queryFn: ... }) — объект, не позиционные аргументы.
8. ЗАБЫЛ __init__.py: Каждая новая модель ОБЯЗАТЕЛЬНО импортируется в models/__init__.py, иначе Alembic её не увидит.
9. ЗАБЫЛ ПОДКЛЮЧИТЬ РОУТЕР: Каждый новый APIRouter — include_router() в main.py с prefix.
10. ТИПЫ НЕ СОВПАДАЮТ: После изменения Pydantic-схемы — обязательно обновить TypeScript-интерфейс на фронте.
